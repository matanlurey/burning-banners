# Original production artwork

All 28 production raster assets were generated for this project using the built-in image generator and then cropped/compressed locally. No reference-module bitmap is used as production art. Geometry and rule legality are determined exclusively by the typed hex graph and engine.

The visual brief used restrained classic fantasy ink and watercolor: storm-blue skies, red banners, parchment-toned cartography, muted forests, inked mountains and legible troop silhouettes. Six generation briefs supplied the final assets:

1. A wide northern fortress panorama with human, dwarf, orc, goblin and undead armies gathering under red standards.
2. A precise 3×2 grid of six faction portraits, ordered Empire, Fjordland, Oathborn, Orcs, Goblins, Army of Night.
3. A precise 3×2 terrain atlas of clear grassland, forest, mountain, swamp, sea and desert cartographic textures, without labels or hex geometry.
4. A precise 4×2 troop atlas: Freeholders, Sea Reavers, Rangers, Berserkir, Oath Takers, Iron Legion, King's Crossbows and Miners.
5. A transparent 3×2 landmark atlas: village, walled city, coastal keep/docks, dwarf mine, necromancer spire and haunted ruin.

6. An original wide Arcane Library illustration of an open spellbook, treasures and a cartographic map, using the same ink/watercolor parchment palette. The generation brief is summarized in the asset manifest; that summary is not a verbatim prompt transcript.

The Arcane Library WebP is 1874×839 pixels, 329,602 bytes, and SHA-256 `a91c465559d5c93eda407565c4dfcee08112b837e7bf4dd6f1bf7491ece61613`. It is a decorative Codex banner and contains no authoritative game data.

Each atlas was visually checked before grid cropping. Landmark alpha was checked and preserved. WebP production paths, dimensions and SHA-256 values are recorded in `content/assets-manifest.json`. These images are decorative originals, not a certified redraw of any printed map or counter.
